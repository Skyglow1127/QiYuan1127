# 独立工程成果

这些项目与PiPER主链路独立，便于分别查看和复现。

- [SFLS 测频正式论文工程](slidedetect/formal_reproduction/README.md)：算法、含噪声仿真、纳赫兹读出和 200 MHz 数字链验证；说明明确区分假设下达标与原文全部复现。[早期工程归档](slidedetect/归档说明.md)继续保留。
- [AIC驾驶实验](aic_driving/归档说明.md)：延迟观测、平顺规划、预测模型和冻结实验。
- [传感器PCB](sensor_pcb/归档说明.md)：四层圆形板工程源与DRC记录。

收录不表示它们属于同一个机械臂系统；具体贡献与证据范围见[成果总览](../docs/成果总览.md)。
