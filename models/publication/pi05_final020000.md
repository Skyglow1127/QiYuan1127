# QiYuan1127 PiPER pi05_final020000

Full native π0.5 expert-B checkpoint, **not a LoRA adapter**. Initialized
from [lerobot/pi05_base](https://huggingface.co/lerobot/pi05_base), with the
PaliGemma vision-language backbone frozen and action expert/action/time
projections trained. Batch size 8, seed 1000, 20,000 total training steps.
Episodes 0–45 were used for training (18,231 frames); episodes 46–51 for
validation (2,257 frames). Best saved validation loss: 0.0672206492 at step 4000.

This repository contains the final step-20000 checkpoint for comparison; the best validation result above belongs to step 4000, not this checkpoint.

Chunk size is 50; the saved policy has `n_action_steps=10`. Some deployment
configurations consume 20 actions; these are runtime choices, not a change
to the saved training configuration. Complete successful real-world grasp
and placement has **not been confirmed** for this version.

The `tokenizer/` folder contains the exact locally reconstructed tokenizer
used in recorded inference, including provenance and checksum evidence.
It is not claimed to be byte-identical to the upstream Hugging Face JSON wrapper.

## Inputs and outputs

LeRobot 0.6.1 policy checkpoint. Inputs: `observation.images.global` and
`observation.images.wrist` (RGB, 640 x 480 before preprocessing) and
`observation.state` (7 values). Output: absolute targets for six arm joints
in degrees and one gripper opening in metres. Camera order, units and
processor statistics must match the training setup.

Dataset: local PiPER red-cube placement demonstrations, 52 episodes,
20,488 frames at 20 Hz. The complete dataset is not published with this model.
The task is to pick up the red cube and place it in the black square on the
left side of the table. No general-purpose robot performance is claimed.

## Reproduction

Source, deployment adapters, known limitations and evidence:
[QiYuan1127](https://github.com/Skyglow1127/QiYuan1127).
Use that project's `scripts/download_models.py` and `scripts/prepare_workspace.py`.
All seven checkpoint files must stay together. Processor safetensors are not
interchangeable across checkpoints. Historical paths in the saved training
configuration document provenance; configure local paths before inference.
A download does not start the robot or authorize physical motion.
