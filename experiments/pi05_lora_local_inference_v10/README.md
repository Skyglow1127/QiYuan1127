# π0.5 + LoRA 本地离线推理实验

本目录是用户提供的“派0.5本地推理”文件夹的发布副本，包含 30 个原文件，共 2,104,088 字节（约 2.1 MB）。程序与结果按版本归档，日期和本机运行标识已脱敏；另补充本 README、[逐文件 SHA-256 清单](source_manifest.json) 和 [入库检查记录](packaging_validation.json)。

## 为什么放在 experiments

这是一组包含程序、输入样本、输出数组、测速报告及历史记录的离线性能实验。整体保存在 `experiments/pi05_lora_local_inference_v10/`，既便于核对程序和结果，也保留程序之间的相对路径。`src/pi05/` 中的专家 B 训练与执行服务继续作为另一组已收录实现；本实验针对 π0.5 基座 + LoRA 020000。全部文件都较小，直接随 Git 仓库提交即可。

## 已保存结果

设备为 AMD Radeon 890M Graphics，PyTorch `2.11.0+rocm7.14.1`，HIP `7.14.60850`；batch=1，BF16。使用同一条录制观察，输出完整 50×7 动作块。

同步测速每种设置预热 3 次、正式计时 10 次：10 步流匹配的预测中位耗时为 **1.3833 秒**，1 步为 **1.0443 秒**。减少步数同时改变动作数值；1 步相对 10 步的关节最大绝对差约 **27.66°**，耗时减少不能单独证明策略效果更好。详见 [同步测速摘要](01_同步推理/结果/run_v10_r33/技术文档可用数据.md)。

同步/异步完整对照固定 10 步流匹配，预热 3 次，2 轮，每组 6 次预测；第二轮反转测试顺序。两轮模拟有效动作频率如下（范围表示两轮结果）：

| 每块消费窗口 | 同步模拟有效频率 | 异步模拟有效频率 |
| ---: | ---: | ---: |
| 10 步 | 5.81–5.84 Hz | 7.91–8.00 Hz |
| 20 步 | 9.02–9.03 Hz | 14.62–14.83 Hz |
| 50 步 | 13.47–13.48 Hz | 约 20.00 Hz |

完整数据见 [同步/异步报告](02_同步与异步对照/结果/run_v10_r35/report.json) 和 [摘要](02_同步与异步对照/结果/run_v10_r35/测速结果.txt)。

计时包含 GPU 同步、动作后处理和输出传回 CPU，不含采图、输入预处理或模型加载。模拟有效频率排除初次预测等待。实验重复使用同一条历史观察，只有一个推理线程，最多预取一块；没有机器人通信、RTC 前缀指导或过期动作裁剪。50 步窗口下约 20 Hz 是模拟队列吞吐，不是实机闭环频率或任务成功率。

## 模型与复现条件

本实验使用原 π0.5 基座和 LoRA 020000，报告中的适配器 SHA-256 为：

```text
8e064a68c5991f1b1321e726d901968c516ec728971aa4b9eb1fc6d4213f14a1
```

已发布到 Hugging Face 的专家 B best004000 完整权重不是本实验的 LoRA 适配器。本目录没有附带基座或 LoRA 权重；报告保留原本机路径，正式复现须准备匹配的模型、tokenizer 和 ROCm 环境。

无需模型/GPU的调度自检，在仓库根目录运行：

```bash
python3 experiments/pi05_lora_local_inference_v10/02_同步与异步对照/程序/benchmark_async.py --self-test
```

正式测速前，在自己的工作副本中调整 `03_公共依赖/activate.sh` 的虚拟环境/缓存路径，以及 `01_同步推理/程序/benchmark.py` 中的基座、LoRA 和 tokenizer 路径，再使用顶层启动脚本。归档中的启动脚本仍保留原环境约定，不是跨机器即开即用入口。异步程序支持 `--output`，同步监管程序支持环境变量 `PI05_BENCHMARK_RESULTS_ROOT`，建议把新结果放入仓库忽略的 `.local/` 目录。

本次上传检查包括原文件复制哈希、Python/JSON 解析、Shell 语法、NPZ 无 pickle 读取、报告与观察样本身份对应，以及假模型调度自检。原 GPU 测速结果按已有证据归档，本次没有重新加载大模型或执行硬件动作。
