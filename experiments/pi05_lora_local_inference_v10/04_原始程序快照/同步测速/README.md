# π0.5 + LoRA 020000 本机测速

本目录使用已经保存的 Piper π0.5 基础模型和 `020000` LoRA，读取此前保存的录制画面与状态，对比 10、5、3、2、1 次流匹配迭代。每次仍输出完整 50×7 动作块。每种设置预热 3 次并正式测量 10 次，相同轮次使用相同随机种子。

在保存工作并关闭不需要的程序后，打开终端执行：

```bash
bash '/home/aup/Documents/Codex/v5/wo-y/outputs/pi05_lora_local_optimization_v10/run.sh'
```

终端实时显示加载和测速进度。结果保存在 `/media/aup/UbuntuData/技术文档/嵌入式比赛技术文档/π0.5本机测速结果/` 下以 `run_` 开头的新目录中。完成后，该目录包含：

- `技术文档可用数据.md`：可用于撰写技术文档的计时口径和统计表。
- `report.json`：每次推理时间、模型路径、LoRA 与输入的 SHA-256、动作差异及环境信息。
- `predicted_actions_by_step.npz`：逐轮、逐方案的完整动作输出。
- `benchmark.log`：模型加载与逐次推理日志。
- `supervisor.json`：进程退出情况与最低可用内存。

计时从预处理后已在内存中的输入开始，到 50×7 动作反归一化、传回 CPU 并完成 GPU 同步为止；相机采集和输入预处理未包含。各设置共享同一模型，减少流匹配迭代次数会改变动作数值，离线数值差异不代表任务成功率。脚本不连接机械臂。
