# 收录范围与来源

本仓库是 2026-11-04 从原工程复制的工程提交版本。原始资料分别为 D1 轨迹改进工程、PiPER 工程、π0.5 专家 B 工作目录、50 MHz FPGA 快照和 VPR3 工程。三份 Word 资产清单用于筛选；未把其中指向本机的链接当成已上传源码。

## 收录

- 当前选定入口、内部包、配置、接口定义、关键测试以及测试实际需要的小型夹具。ACT 启动必需的两份基线身份 JSON 保留，未复制整套历史源码或权重备份。
- D1 共同进度候选和明确标为未编译的 timed_group 机载源码。
- PiPER 共享相机、官方录制适配和执行后端；ACT 与 π0.5 共用这份源码。
- π0.5 B 的训练与完整模型推理；无损协议回归所需的旧服务 5 个参考文件作为测试夹具保留，不是另一个部署推荐。
- 三个选定模型的 JSON 配置及归一化 / 反归一化 safetensors 小文件。
- 一份录制输入样本、数据元信息、代表性原报告和错误边界。

- 当前执行链使用的 pyAgxArm 1.0.0 源码快照及原许可证；公开版本提供当前 SDK 文件，见 [SDK 说明](sdk/README.md)。

- 用户指定的 π0.5 + LoRA 本地推理实验完整文件夹，单独放在 `experiments/pi05_lora_local_inference_v10/`；包括小型 NPZ 输入/结果、原日志与历史未完成记录，文件身份见其 `source_manifest.json`。

## 排除

除明确收录的 pyAgxArm SDK 外，不复制虚拟环境、其他第三方整库、历史源码备份、旧批准与实机 trial、退役录制器、完整视频与数据集、训练中间检查点、特征缓存、Vivado 构建缓存。已完成 FPGA 交付版本的 bitstream、XSA 与设备树二进制作为明确例外收录，见下文。

本版不收录 D1 ACT / PREACTION / 历史 Qwen、YOLO 等独立候选实验，也不收录 PiPER 第二轮 ACT 与早期 LoRA 的全部成果。这些属于前次筛选中的可选历史材料，原工程中仍保留。当前侧重三条选定路线的工程实现。

## 来源与修改

[逐文件清单](source_manifest.json) 保存来源代号、原文件相对路径、原 SHA-256 与提交副本 SHA-256。未改动的文件两者相等。原工程的完整本机映射另存 `.local/source_manifest.json`，不提交。用户本次明确提供的 SDK 原始路径清单单独收录于 `docs/sdk/original-paths-sha256.tsv`，用于溯源。

对公开云主机标识做模板替换；历史 README 补加醒目的历史状态说明。未调整控制算法、数值参数、模型权重或原始结果。发布版源码中的本机路径属于来源记录，可由准备脚本在独立工作副本中迁移。

原现场地址、相机序列号和标定值不具有跨设备通用性。新设备须自行配置。没有把历史 approval、grasp_plan、trial 或使能状态作为可复用执行凭据。

## 外部大资产

大型权重和完整数据集继续留在原位置，没有搬动或重复复制。`.local/artifact_locations.json` 是本机接入索引，不会提交。实际推送时只包括 `models/` 中的小配置、统计与下载说明。

根目录没有为全部代码和模型擅自指定统一开源许可证。第三方源码片段、机械网格、模型及 SDK 的来源见 THIRD_PARTY_NOTICES.md。

## 当前交付与历史基线

当前 FPGA 工程使用 `hardware/fpga_project_20261104/`；早期 FPGA 状态与验证材料归入 `docs/history/fpga_50mhz/`。原 `hardware/robot_rt_50mhz/` 保留供历史回归使用。项目首页按当前成果导航，阶段过程与版本边界在 `docs/RESULTS.md` 中维护；原始报告中的状态和数值不作改写。

当前 FPGA 的 `上板文件/` 已补齐 `robot_rt.bit`、`robot_rt.bit.bin`、`robot_rt.xsa`；`板端配置/` 已补齐 `robot_rt.dtbo`。前三者按原产物清单校验，仓库检查工具仅为这组指定路径放行二进制交付物。文件直接复制自已发布工程，补齐文件不改变原清单中的板测状态。

后续板测证据归入 `hardware/fpga_project_20261104/上板测试_20261104/`：保留成果状态、静止测试、ACT 回放输入/期望/板端快照及成功测试所用脚本。重复固件和设备树复用原位置，排除运行日志及已编译的 MMIO `.so`，保留 C 源码。构建时清单与后续板测结果分开保存，不改写原始状态字段。

上板测试目录仅发布已通过项目的资料；成果状态与成果说明为筛选后的发布摘要，清单同时记录其原始哈希和发布哈希。原始测试数据保持字节一致，本机源目录保留完整资料。

ACT、π0.5 与 π0.5 + LoRA 的发布文件使用版本号和运行编号代替开发日期及本机运行路径中的时间标识。助手交接文档不纳入发布；测试数值、模型步数和验证结论保持不变。配置中的版本路径是发布别名，部署时使用 `scripts/prepare_workspace.py` 和实际资产配置生成工作副本。原始文件与日期对应关系仅留在本机。
