Dataset original mean/std/min/max, complete input shapes, versions, source paths and SHA256 are in `act_contract.json`. Dataset image statistics differ from the saved ImageNet image statistics by design. Dataset gripper values include a negative tail; no implicit correction is hidden in normalization.

`ActionPostprocessor.denormalize()` is the unchanged numerical path. Bounds rejection, explicit optional projection with correction flags, and Q16.16 encoding are separate. The six degree axes and metre gripper retain their own units in Q16.16.

Q16.16 integer codes are constrained to `ceil(lower × 65536)` through `floor(upper × 65536)`. Non-grid endpoints round inward and can have an error approaching one LSB; intervals with no representable int32 code are rejected. A 0.1 m upper endpoint encodes as 6553, never 6554.

The local training shell script describes a CPU preparation path; the saved train_config records the actual cloud CUDA batch-8 training. Neither saved CUDA configuration nor filename implies that offline execution uses a GPU.

This contract establishes software semantics. It does not establish physical command acceptance, placement success or collision safety.
