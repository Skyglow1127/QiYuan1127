# 阶段B：模型与执行参考之间的契约

本文数值证据对应B提交 `b05a088` 的30步快照。用户随后另改当前旧部署为50步；该变化不回写历史证据。原生PL段格式和当前C设计决策见 [PL_SPEC.md](PL_SPEC.md)，不将本浮点参考直接宣称为已验证RTL。

当前是离线适配与算法验证，无机械臂/相机/CAN连接，无PL传输后端。原ACT部署继续使用原入口、原权重与原保护；本目录不自动接管。用户已删除无法执行的A项目，本文没有补测A的入口条件。

## 输入与单位

真实契约由 `act_contract.json` 和 `ACT_CONTRACT.md` 生成：双路RGB，顺序global/wrist，各480×640×3、uint8 HWC；七维状态为六关节deg和夹爪m。`ObservationBuilder` 转成float32 CHW/255，再由保存的官方processor加batch并归一化。训练配置关闭augmentation和resize，图像使用保存的ImageNet统计，不能替换成dataset图像mean/std。

ACT输出是归一化的100×7预测。`ActionPostprocessor.denormalize` 只运行保存的反归一化一次；该路径用于与官方数值比较，不夹断模型值。部署参考路径另行显式选择越界拒绝或 `project(..., clip=True)` 并记录修正，再编码Q16.16。默认越界拒绝。Q16.16每轴单位仍是六个deg、一个m，不能把夹爪m当deg或mm。

Q16.16采用nearest/ties-to-even，再保守收回到 `[ceil(lower×65536), floor(upper×65536)]` 的可表示整数域，拒绝空域和int32溢出。这样0.1m不会因普通四舍五入变成越界的0.1000061m；端点误差可接近一个LSB，完整验收容差按1LSB，而非所有情形都声称半LSB。

归一化一致不等于命令可执行。B5录制样本的部分模型提议超出当前部署包络；报告会分别列出纯模型差值、越界数和合法域量化误差。不得因纯模型比较为零就跳过保护。

## 四个部件与模型替换

| 部件 | 当前职责 | 不承担的职责 |
|---|---|---|
| ObservationBuilder | 模型所需键、RGB顺序、dtype、device、官方预处理 | 相机采集或旧帧刷新 |
| ActionPostprocessor | 官方反归一化、物理单位、显式限幅/拒绝、Q16.16 | IK假设或机械安全证明 |
| ChunkScheduler | 原时间轴、序号、消费窗口、过期槽、边界DQ_MAX | 重新打来源时间或连接硬件 |
| Ensembler | 默认none；可显式选择有状态一阶混合 | 静默启用ACT temporal ensemble |

通用执行层只接收NxD物理值和同维限值。换模型时更换前两项及其契约，调度/插值不依赖ACT类。当前动作空间为关节位置，无需IK；未来EEF适配器若IK失败，拒绝该块，不能把无解结果送入通用层。

## 块字段与时间轴

`TimedChunk` 在离线参考中包含：

| 字段 | 含义 |
|---|---|
| sequence | 严格递增块序号，重放/倒序拒绝 |
| observation_at | 原始观测单调时刻，后续不重打 |
| produced_at | 推理完成时刻，不得早于观测或晚于接收时的now |
| sample_hz | 模型动作时间采样率，当前从dataset读取为20Hz |
| targets | NxD有限物理目标，不可变副本 |

第i槽绝对时刻 `slot_at = observation_at + i/sample_hz`。每次重规划都有自己的真实观测时刻；不能用固定块序号乘周期代替实际有推理延迟的观测来源。保存配置消费100步，当前部署覆盖为30步；模型仍预测100步。普通名义消费时长30/20=1.5秒，实际循环还含推理/采集等待；100步预测时域为5秒。已有条件续20步是独立部署逻辑，不在通用调度器内猜测放置阶段。

`ACTQueueAdapter` 用来证明官方队列30步语义一致，本身不包含时钟/安全传输。`ChunkScheduler` 则实现明确的来源与槽时效，二者不能不经审查就当成旧部署的逐行替代。

特别是通用层 `source_max_age_s` 定义为整块原观测寿命：设0.4秒就不能执行该来源的1.5秒轨迹。离线回放所给寿命属于场景输入，并未改变旧部署任何时效。改变真实执行保护不能以本离线证明替代。

## B3合议选择

| 方案 | 实际延迟代价 | 复杂度与失败模式 |
|---|---|---|
| 保持none，当前选择 | 无额外合议等待；块接缝由独立整形参考验证 | 保留保存模型的null系数；原始边界可能跳变，需要DQ_MAX与导数约束 |
| PC端官方ACT temporal ensemble | 每次求值需新预测的算力，不能概括成必等一个完整chunk | 采样/观测率及调用节奏改变；当前CPU性能不能默认支持20Hz逐步新推理 |
| 显式一阶混合 | 不需等待未来块，但有滤波滞后 | alpha和状态须明确；不是官方ACT时间集成，也不能证明机械消抖 |

当前不启用temporal ensemble，不改原部署alpha0.5。新参考轨迹的C2整形与原部署轻度目标滤波是独立算法，未接入实机。

## B4频率映射与有界参考

`f_exec` 没有硬件实测值，不设默认部署率。回放必须显式提供 `--f-exec`，其结果标记 `design_test_only`，物理频率字段保持null。`K=f_test/20` 可以为整数或非整数；参考每个tick由整数索引除以显式率得到绝对时刻，不通过反复累加周期制造漂移。未来PL可用相位累加器实现同一时间映射，本轮不写RTL。

`MotionBounds` 的位置、速度、加速度、jerk、DQ_MAX全部是显式同维参数。`QuinticSegment` 验证解析极值；固定tick的 `C2Tracker` 对一段常jerk做精确积分并约束整个连续区间，使位置/速度/加速度连续。不存在可行区间时拒绝，不能瞬间改为零速来伪造HOLD。

录制回放比较每个消费窗口只取一步、线性重采样及C2参考，并用**同一C2算法**生成ps_baseline，使控制律改变和执行时钟来源分开。数值jerk对照使用同一物理滤波口径；解析jerk上界另列，不用滤波后指标掩盖原始跳变。跟随偏差/引入滞后必须与jerk一起报告。

## B7降级

| 触发 | 离线实现动作 |
|---|---|
| 推理时间超过消费周期一半 | 发出建议事件；不自动改分辨率/归一化/模型或原消费步数 |
| 块迟到或STARVE | 停用过期目标，按已声明导数上限制动，再HOLD |
| 超过两个消费周期仍未停 | 报FAULT，不能强造瞬时HOLD；真实系统仍需原保护处理 |
| 观测过期/未来时间/时钟倒退 | 拒绝新块与无效时刻；不延长旧来源寿命 |
| 越界或IK失败 | 拒绝整块，保留上一条有效参考用于有界制动；不重发过期旧块 |

任务书STARVE中的“时间缩放”不能改变原来源截止时刻。本实现选择立即有界制动，保留原时效语义；这比延长旧块寿命更容易给出明确故障边界。以上是软件参考和注入测试，不是已上板的保护通路。

## 验证边界

B1证明同一个录制解码RGB输入的预处理一致，不证明实时MJPEG与训练H264存储像素完全相同。B5证明模型和数据边界的数值一致，不证明越界预测可执行。B4证明显式场景的参考轨迹，不证明硬件可接受该测试率。B6基于实际CPU后端，不将890M硬件存在等同于GPU推理。
