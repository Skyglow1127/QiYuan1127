# D1-T 从臂实机动力学校准

这里给出实测与辨识流程，尚未连接实机、采集数据或得到校准结果。先核对铭牌、固件、夹爪及末端附件版本：D1-T 产品页与官方开发页的 D1-550 参数不同，不能混用。

## 先确认能测到什么

[宇树官方 D1 服务文档](https://support.unitree.com/home/en/developer/D1Arm_services)公开的高层接口描述了约 10 Hz 的关节角度反馈和运动命令。开始辨识前，向宇树确认你的固件能否读到**同步时间戳、实际关节角度/速度、电流或实际关节力矩、温度**，以及真实采样频率、滤波和单位。不要把目标位置、目标力矩、使能力、厂商未标定的“负载百分比”当作实际力矩。

- **只有 10 Hz 角度**：可校正零位、运动方向、限位、低速位置响应；配合独立测量可做质量/质心校准。不能仅凭这些角度唯一辨识完整质量、惯性、摩擦及电机力矩常数。
- **有经过标定的电流或力矩**：可以做重力与摩擦辨识；有足够带宽的同步反馈时，再做动态惯性辨识。建议争取 200 Hz 及以上的真实同步记录，但这是实验建议，不是对 D1-T 接口能力的保证；最终由信号带宽、控制器和可用采样率确定激励频率。对 10 Hz 数据插值到 1 kHz 不会增加信息。
- **没有可信的力矩通道**：先用经过标定的外部力/力矩传感器、已知载荷或合适的测力工装建立测量依据；不要由闭环位置误差直接反推力矩。

## 1. 确立几何、零位和质量基准

将基座固定到刚性工装，核对每轴正方向、零位、单位和减速器编码器换算。用外部测量检查数个末端位姿，先排除关节零偏/轴方向/工具坐标错误；这些错误会被错误地“拟合成”质量或摩擦。

称量**实际装配状态**的总质量，区分底座、移动连杆、舵机、夹爪、线缆和新增末端工具。若有厂商认可的分组件数据或可维护的拆装条件，分别称量每个刚体及附件，并核对其在 URDF 中归属哪个 link。无需为了辨识随意拆开封装舵机。

当前官方模型 link 质量合计 0.719136 kg，明显不同于 D1-T 产品页约 2.37 kg。不能简单把全部 link 的质量与惯性乘以 `2.37/0.719136`：缺失质量的分布、固定/运动部分及真实质心未知。

质心可从可信 CAD 装配质量属性获得，或用多方向支承反力/悬挂平衡实验估计；末端新增夹具和工具必须独立建模。惯性可用可信完整 CAD、合适的摆动工装或后续动力学辨识补充。

## 2. 标定力矩测量比例和偏置

确认“电流”是相电流、q 轴电流还是电源总电流。只有合适的电机电流反馈才可经模型换算电机/输出轴力矩。对每轴建立有效标定关系，例如：

`tau_joint ≈ k_eff * (current - current_offset)`

这里 `k_eff` 综合了电机常数、传动比及传动效率等影响，不应未经测量就固定为 `N * Kt`。效率可能随方向和负载变化，静摩擦与传动预紧也会引入偏差。

采用已知质量和已知力臂的工装，在多个静态姿态比较加/卸载前后的力矩变化。单轴简单工况可用 `Δtau = (r × ΔF) · axis`，整臂已知末端载荷可用 `Δtau = J(q)^T Δwrench`。注意力、力矩、雅可比必须在一致坐标系中表达。正反方向接近同一姿态、重复测量，以分离偏置、滞回与摩擦；不要只做一个姿态的一次标定。

## 3. 先辨识重力，再辨识摩擦

**重力实验：**选择多组无接触、无自碰撞的静止姿态，覆盖不同肩/肘/腕组合。每个姿态等待速度和电流稳定后取平均。组合空载与数个已知载荷数据，拟合重力项中的质量和一阶质量矩 `m*c`。用同一路径两个方向到达同一姿态，评估静摩擦/滞回对结果的影响。

**摩擦实验：**固定其余关节，对待测关节做多个低速、正反向匀速段；扣除已辨识的重力和已知外载后，再拟合黏性摩擦、库仑摩擦及偏置。若数据支持，再引入 Stribeck/方向不对称模型。零速附近有静摩擦，不能简单用 `sign(0)` 处理整个停止过程。

记录温度，尽量在相同热状态下对比；不要将升温导致的变化全部归入惯性参数。

## 4. 动态激励与参数辨识

在可靠力矩反馈、关节限位和工作空间确认后，从低速、小幅、无载激励开始，再逐步扩大到正常工作的范围。采用多关节多正弦或平滑傅里叶轨迹，使姿态、速度和加速度有足够独立变化；无需接近机械极限。先离线检查轨迹及过渡段的碰撞、速度、加速度和力矩需求。实机必须有可触及的硬件停机方式，网页“保持”不是实机急停。

同步记录：

| 字段 | 内容 |
|---|---|
| t | 单调时间戳，秒；记录丢帧和时间抖动 |
| q / dq | 六轴实际角度 rad、速度 rad/s |
| tau 或 current | 实际测量值，注明单位和换算模型 |
| q_command | 指令值，用于分析延迟与跟踪误差 |
| temperature | 各舵机温度及测量时刻 |
| payload | 质量、质心、惯性及安装位姿 |
| metadata | 硬件/固件、控制模式、限幅、滤波设置 |

使用有明确带宽的滤波/平滑方法估计加速度，保留原始数据；对齐时钟和测量延迟。直接对低频、量化、有噪声的角度做两次差分通常会严重污染惯性辨识。

可采用模型：

`tau = Y(q,dq,ddq)*theta + Jr*ddq + Fv*dq + Fc*tanh(dq/v_eps) + bias`

`theta` 为刚体惯性参数组合；`Jr` 为适用时的等效转子/传动惯量。载荷的惯性或外部 wrench 应明确建模，不要重复计入。未知内环控制和执行器延迟也要单独处理，不能靠修改 link 惯性“吸收”所有误差。

用 QR/SVD 检查回归矩阵的秩与条件数，辨识可观测的**基参数**，不是假定每个 link 的所有参数都能独立测出。加入实测质量、CAD 几何等先验与物理一致性约束：质量为正、惯性对称、主惯量非负并满足三角不等式、质心在合理体积内。可采用约束最小二乘/半正定方法。[物理一致惯性辨识论文](https://arxiv.org/abs/1701.04395)与[包含摩擦和电机参数的辨识论文](https://arxiv.org/abs/1410.4410)说明了这些问题。

## 5. 用未参与拟合的数据验收，再写回模型

按**完整轨迹/实验批次**划分训练和验证集，不要随机拆相邻样本来获得虚高结果。使用新的姿态、速度和载荷检验：

- 关节力矩预测 RMSE、最大误差、方向性/温度相关残差。
- 末端静态下垂及外部测量位姿误差。
- 低速摩擦、正反向滞回、动态相位和跟踪误差。
- 未用于拟合的载荷与速度工况。

验收阈值应由你的任务精度、传感器噪声和实际工作范围确定。先验证动力学，再调整仿真 PID；**单纯调到仿真动作像实机，不等于动力学参数正确**。

写回 `config/model.yaml` 的 `mass`、`com`、`inertia` 时，URDF 的 inertia 应表达在 `<inertial origin>` 指定的质心坐标系。若辨识得到的是 link 原点处惯量 `I_O`，需用平行轴定理转换：

`I_C = I_O - m * ((c·c)*Identity - c*c^T)`

若惯性坐标系相对 link 有旋转，还需做张量旋转变换。当前 Xacro 的惯性坐标轴与 link 平行；不要直接填入不同轴系的六个数。

关节摩擦/阻尼在 `urdf/d1_macros.xacro` 的 `<dynamics>` 中；若要使用非线性摩擦或转子惯量，应增加相应动力学实现，并避免与其他模型重复计入。夹爪齿轮/连杆传动、电机转角到指位移的映射，以及夹持力应单独标定。

保存旧模型、原始测量、参数置信区间、辨识脚本、验证集结果和硬件版本。重新生成 URDF，复跑运动及碰撞测试后再使用。
